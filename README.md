# WINDOWTAPPER
recreation of [this youtube video](https://www.youtube.com/watch?v=mzoCbcC4P90) and you can actually have it run on your pc

how to download:
- scroll to the top of the page
- on the right side, you'll see the releases category
- click on 1.0 (or any current version)
- click WINDOWTAPPER.exe
- that's it

tips for using the source code:
- use godot engine 4.6 and higher
- that's it
